# Revert Guide — Your Journey in Islam

A comprehensive interactive guide for new Muslims covering beliefs, prayer, lifestyle, and community support.

## Features

- 🕌 **Shahada Guide** — How to take your testimony of faith with Arabic text and meaning
- 📿 **Five Pillars** — Detailed expandable section on each pillar
- 🧎 **Prayer Guide** — Wudu steps, Salah steps, prayer times
- 📖 **Essential Surahs** — Al-Fatiha (complete), Al-Ikhlas, Al-Falaq, An-Nas, Ayatul Kursi
- 🤲 **Ghusl Guide** — When required and step-by-step instructions
- 🍽️ **Lifestyle** — Halal food, Islamic dress, community, character
- 📚 **Resources** — NewMuslims.com, recommended books, continuing education
- 📿 **Daily Prayer Tracker** — Track 5 prayers with streak counter
- 🌙 **Dark/Light Theme** — Toggle with persistence
- 📱 **PWA Support** — Works offline after first visit

## Quick Start

```bash
cd Revert-Guide
python3 -m http.server 8080
# Open http://localhost:8080
```

## Tech

Single-file HTML/CSS/JS application. No build step, no dependencies.
